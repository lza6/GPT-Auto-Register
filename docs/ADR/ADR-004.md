# ADR-004: 启动脚本的编码与命令劫持防御基线

**状态**：已采纳（2026-08-05）
**关联**：`启动.bat`、`停止.bat`、`install_camoufox.ps1`、`.specify/specs/v2.0.4-bat-crash-fix/`
**修复提交**：`ed769f0`（v2.0.4）

## 背景

v2.0.3 发布后用户报告"双击 `启动.bat` 闪退"。复现发现 bat 在 3 秒内 rc=255 退出，连日志都来不及写。根因是双重环境陷阱：

1. **中文编码错位**：`启动.bat`/`停止.bat` 为 UTF-8 无 BOM 且含中文注释/echo。Windows cmd 按系统默认代码页（中文 Windows 为 GBK/936）读取 bat 字节流时，中文字节被当作 GBK 多字节字符的首字节与后续字节错位组合，破坏 bat 词法，导致 `cd /d "%~dp0"` 失败（"系统找不到指定的路径"）→ 工作目录停在 system32 → 后续所有相对路径全废 → rc=255 闪退。
2. **GNU timeout 劫持**：即便编码正确，`timeout` 命令被 Git for Windows 的 GNU coreutils `timeout.exe` 劫持（PATH 优先级高于 `System32\timeout.exe`），`timeout /t N /nobreak` 被解析为 Unix `timeout '/t'`，报 `invalid time interval`，CF Solver 轮询/服务重启定时链路中断。

复现过程中还发现：`subprocess.Popen(["cmd","/c",bat])` 在中文路径下 cwd 传递乱码；`cmd /c` 带空格路径会被 shell 切词；Git Bash→cmd 的 cwd 中文传递系统性破坏。**真实双击行为必须用 `os.startfile`（ShellExecuteW）模拟**，不能用 CreateProcessW。

## 决策

启动脚本建立"编码与命令劫持防御基线"，三条硬规则：

1. **纯 ASCII**：所有 `.bat` 脚本字节级纯 ASCII（中文 rem/echo 译为英文）。任何代码页（GBK/UTF-8/ANSI）下解析字节一致，彻底免疫编码错位。**禁止在 bat 内写中文**，包括注释。
2. **Windows 原生命令+绝对路径**：`timeout /t N /nobreak >nul` → `ping -n N+1 127.0.0.1 >nul`（Windows 原生，免疫 GNU 劫持）；`chcp 65001` → `%SystemRoot%\System32\chcp.com 65001`（绝对路径，免疫 PATH 劫持）。
3. **定时语义对齐**：`ping -n N+1` 实际等 N 秒（ping 发 N+1 个包间隔 1 秒，首包立即发），与原 `timeout /t N` 等 N 秒对齐。

## 后果

- **正面**：双击闪退根除（main=True cf=True，端口 23457/8001 均 Listen）。新机器 clone 后双击即可拉起。任何代码页/任何 PATH 配置都能跑。
- **正面**：可排障性提升——bat 纯 ASCII，用户看 bat 源码能直接理解逻辑，无中文乱码干扰。
- **负面**：bat 注释变英文，中文母语者阅读门槛略升（可接受，bat 注释本就简短）。
- **负面**：`ping -n N+1` 比 `timeout /t N` 多打一次包，但本地回环无成本。

## 替代方案

- **UTF-8 with BOM**：cmd 能识别 BOM 切换 UTF-8 解析。**否**——BOM 在某些工具链（git diff/ PowerShell 5.1 读取）会引入不可见字符，且不解决 GNU timeout 劫持。
- **chcp 65001 后保留中文**：依赖 chcp 行先执行。**否**——若 bat 本身含中文，chcp 行之前的中文 rem 已被 GBK 错位解析，chcp 来不及生效。
- **移除 Git for Windows 的 GNU 工具**：治本但激进，破坏用户其他工具链。**否**——让项目适配环境，而非让环境适配项目。
- **改用 PowerShell 启动脚本**：PowerShell 对 UTF-8 处理更好。**否**——`.ps1` 双击默认 ExecutionPolicy 受限，需 `powershell -ExecutionPolicy Bypass`，门槛比 `.bat` 高；`.bat` 是 Windows 双击启动的事实标准。

## 验证

- 字节级：`启动.bat`/`停止.bat` 非 ASCII 字节数 = 0。
- 行为级：`os.startfile` 真实双击模拟 → 120s 内 23457+8001 均 Listen；`cf_solver.log` 产生新日志。
- 回归：上轮 190 项 pytest 全绿（本轮未动后端代码）。

## 适用范围

所有 Windows `.bat` 启动脚本。PowerShell `.ps1` 脚本（如 `install_camoufox.ps1`）可保留中文注释（PowerShell 5.1+ 对 UTF-8 BOM 处理较好，且 .ps1 不通过 cmd 词法解析），但建议也尽量精简中文。
